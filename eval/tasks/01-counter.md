Build a counter app.

Requirements (all texts exact):

- A button whose text is `+` and a button whose text is `-`.
- An element whose text is `count: N`, where N starts at 0. Clicking `+`
  increments N by 1; clicking `-` decrements it by 1.
- An element whose text is `doubled: M`, where M is always 2×N and must be
  computed as a derived value, not stored separately.
- An element with id `parity` whose text is `even` when N is even and `odd`
  when N is odd.

All displayed values must update immediately on every click.
