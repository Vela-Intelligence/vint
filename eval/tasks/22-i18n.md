# Task: a multilingual list

Build a single-page item list whose UI language switches at runtime. Every
requirement below is exact and all of them must hold at once. Export
`mountApp(container, deps)`; `deps.messages` is a plain object (not a
promise) of this shape, one entry per locale:

    { [locale: string]: {
        dir: "ltr" | "rtl",
        title: string,        // the heading
        add: string,          // the add button's label
        placeholder: string,  // the input's placeholder
        empty: string,        // shown when there are no items
        count: { [category: string]: string }   // templates keyed by Intl.PluralRules
      } }                                       // category; "{n}" stands for the number

Use ONLY `deps.messages` for data — no other IO, no timers.

LOCALE
- A `<select>` with attribute `data-locale` whose `<option>`s are the locale
  codes from `Object.keys(deps.messages)`, in that order, each option's
  `value` and text being the code. The first code is the initial locale.
  Changing the select's value changes the current locale.
- `document.documentElement` carries attribute `lang` equal to the current
  locale and attribute `dir` equal to that locale's `dir`, set at mount and
  updated on every locale change.
- An `<h1>` whose text is the locale's `title`.
- An `<input type="text">` with attribute `data-new`, attribute `dir="auto"`,
  and `placeholder` equal to the locale's `placeholder`.
- A `<button>` with attribute `data-add` whose text is the locale's `add`.
- Every label above follows the locale immediately when it changes.

ITEMS
- Clicking the add button, or a `keydown` of `Enter` in the input, adds the
  input's trimmed value as an item and clears the input. A value that is
  empty after trimming adds nothing. A `keydown` whose `isComposing` is
  true is the input method committing text, not a submission: it adds
  nothing.
- Items render as `<li>` elements inside a `<ul>` with attribute
  `data-items`, in insertion order. Duplicates are allowed. Each `<li>`
  contains an element with attribute `data-text` whose text is the item's
  text EXACTLY as entered (no Unicode normalization, no trimming beyond
  the add step) and a `<button>` with attribute `data-remove` that removes
  that item.
- `<li>` elements keep their DOM identity (the same element object) across
  a locale change and across the removal of other items.

COUNT
- An element with attribute `data-count` whose text is the current
  locale's `count` template for the category
  `new Intl.PluralRules(locale).select(n)` — n is the number of items —
  falling back to the `other` template when the category has none, with
  `{n}` replaced by `new Intl.NumberFormat(locale).format(n)`. Always
  current: it changes with every add, remove and locale change.
- An element with attribute `data-empty` whose text is the locale's
  `empty`, present in the DOM ONLY while there are no items (removed, not
  hidden, once an item exists).

Example `deps.messages` (the test uses different strings; do not hard-code
these):

    en: { dir: "ltr", title: "Shopping list", add: "Add", placeholder: "New item",
          empty: "Nothing yet", count: { one: "{n} item", other: "{n} items" } }
    fr: { dir: "ltr", title: "Liste de courses", add: "Ajouter", placeholder: "Nouvel article",
          empty: "Rien pour l'instant", count: { one: "{n} article", other: "{n} articles" } }
    ar: { dir: "rtl", title: "قائمة التسوق", add: "أضف", placeholder: "عنصر جديد",
          empty: "لا شيء بعد", count: { zero: "لا عناصر", one: "عنصر واحد", two: "عنصران",
                                       few: "{n} عناصر", many: "{n} عنصرًا", other: "{n} عنصر" } }
